EeveeSpotify Version Update Locations
=====================================

When bumping the version, update these 2 files:

1. control
   - line 3: `Version: X.X.X`   <- the .deb package version

2. Sources/EeveeSpotify/Tweak.x.swift
   - the `static let version = "X.X.X"` constant (the tweak's runtime version)
   - line numbers drift, so find it instead of trusting a fixed one:
       grep -n 'static let version' Sources/EeveeSpotify/Tweak.x.swift
   - note it sits far down the file (~line 292 as of 2026-10-12); do not go
     looking for it near the top

Both must match for consistent versioning across:
- .deb packages (control)
- Tweak runtime (Tweak.x.swift)
- IPA builds (they report the tweak version)

There is NO third place to edit. build-ipa-local.sh reads the version out of
control at run time:

    VERSION=$(grep -E '^Version:' control | awk '{print $2}')

so it can never drift from control.
