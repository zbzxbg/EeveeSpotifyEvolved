# Strings this project ships in English on purpose.
#
# Tools/l10n_lint.py subtracts these keys from each locale's untranslated count, so a
# locale can report "0 untranslated" while still showing English here. Nothing blocks
# translation: an entry present in a locale file is used as usual, the list only decides
# what contributors are expected to do.
#
# Criteria for adding a key:
#   - the English value quotes identifiers, flag names, log syntax or example values the
#     user has to type or match verbatim, so a translation would stop matching reality;
#   - a ported feature's manual page, where the paragraphs buy the least value per word.
#
# One key per line. `#` starts a comment. Exact key names only — an entry whose key no
# longer exists in en.lproj is reported as stale by the linter, so delete it then.
